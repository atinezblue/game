## app-ads.txt

The authoritative copy is served from the domain root at
[https://atinezblue.github.io/app-ads.txt](https://atinezblue.github.io/app-ads.txt),
hosted in the `atinezblue.github.io` repo. AdMob's crawler only reads the
domain root, so the copy in this repo is served at `/game/app-ads.txt` and is
never crawled. It is kept as a fallback in case this repo is later given its
own custom domain. Keep both copies in sync.
